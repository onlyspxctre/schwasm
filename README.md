# schwasm — GCPU Assembler

A lightweight assembler for **G-CPU**, targeting a 4K×8 ROM with a 12-bit address bus, outputting a `.mif` file.

## Features

- Assembles GCPU instructions into Intel-style memory initialization file (`.mif`)
- Supports immediate addressing with hex (`$`) and decimal literals
- Built on in-house tokenizer (`splexer`) backed by (`sptl.h`)

## Building

```bash
make
```

## Usage

```bash
./schwasm <input.asm>
```

The assembler reads assembly source and writes a `.mif`-format memory file to stdout.

## Example

**input.asm:**
```asm
LDAA #$26
```

**output.mif:**
```
--      Generated by Schwasm.      --
DEPTH = 4096;
WIDTH = 8;

ADDRESS_RADIX = HEX;
DATA_RADIX = HEX;

CONTENT
BEGIN
    0000 : 26;
END;
```

## Supported Instructions

| Mnemonic | Description          |
|----------|----------------------|
| LDAA     | Load register A      |
| ORG      | Set origin address   |
